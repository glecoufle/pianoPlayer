# Fichiers Audio pour les Notes

Placez les fichiers audio WAV des notes dans ce dossier avec les noms suivants :

## Fichiers requis :

- `F3.wav` - Fa Grave
- `G3.wav` - Sol Grave
- `A3.wav` - La Grave
- `B3.wav` - Si Grave
- `C4.wav` - Do Medium (Do central)
- `D4.wav` - Ré Medium
- `E4.wav` - Mi Medium
- `F4.wav` - Fa Medium
- `G4.wav` - Sol Medium
- `A4.wav` - La Medium
- `B4.wav` - Si Medium
- `C5.wav` - Do Aigu
- `D5.wav` - Ré Aigu
- `E5.wav` - Mi Aigu

## Notes sur les fréquences :

- F3 (Fa Grave) ≈ 174.61 Hz
- G3 (Sol Grave) ≈ 196.00 Hz
- A3 (La Grave) ≈ 220.00 Hz
- B3 (Si Grave) ≈ 246.94 Hz
- C4 (Do Medium) ≈ 261.63 Hz
- D4 (Ré Medium) ≈ 293.66 Hz
- E4 (Mi Medium) ≈ 329.63 Hz
- F4 (Fa Medium) ≈ 349.23 Hz
- G4 (Sol Medium) ≈ 392.00 Hz
- A4 (La Medium) ≈ 440.00 Hz (La de référence)
- B4 (Si Medium) ≈ 493.88 Hz
- C5 (Do Aigu) ≈ 523.25 Hz
- D5 (Ré Aigu) ≈ 587.33 Hz
- E5 (Mi Aigu) ≈ 659.25 Hz

## Format recommandé :

- Format : WAV (non compressé)
- Qualité : 44.1 kHz, 16-bit minimum
- Durée : 1-2 secondes par note
- Volume : Normalisé et équilibré entre toutes les notes

## Sources possibles :

Vous pouvez créer ces fichiers avec :

- Un piano numérique/synthétiseur
- Des bibliothèques d'échantillons audio gratuites
- Des générateurs de tons en ligne
- Des DAW (Digital Audio Workstations)
